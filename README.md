# Organização de Preços de Supermercado

## Sobre o projeto

Projeto acadêmico desenvolvido em linguagem C com o objetivo de praticar lógica de programação, vetores, estruturas de repetição e algoritmos de ordenação.

## Funcionalidades

- Armazenamento de 10 preços de produtos.
- Exibição dos preços originais.
- Ordenação crescente utilizando Bubble Sort.
- Ordenação decrescente utilizando Bubble Sort.

## Tecnologias utilizadas

- Linguagem C
- GCC
- Visual Studio Code

## Como executar

Compile o programa:

```bash
gcc main.c -o supermercado
```

Execute no Windows:

```powershell
.\supermercado.exe
```

## Objetivo

Desenvolver conhecimentos fundamentais de programação e algoritmos por meio de um exercício prático.
